## 👥 СОВМЕСТНАЯ КОМАНДНАЯ РАБОТА

1. Любой участник рабочей группы может вносить корректировки в дорожную карту или смету прямо в браузере (LocalStorage).
2. Нажмите кнопку **«Экспорт всей модели (JSON)»** в шапке сайта для сохранения файла состояния.
3. Отправьте JSON-файл коллеге.
4. Коллега нажимает **«Импорт правок коллеги»** — и все параметры синхронизируются в его браузере!
