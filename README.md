# ЗаБег.РФ — Камчатка 2027

Рабочая региональная концепция: участникам, оргкомитету и потенциальным партнёрам. Проверка и обновление оформления — 09.11.2026.

Платформа содержит переключение четырёх проектных маршрутов, восемь функциональных зон стадиона, дорожную карту, редактируемую смету на 29 исходных статей, сценарий платных слотов, конструктор предложения и десять исходных DOCX-пакетов.

## Подтверждённое и проектное

Дата всероссийского события 22 мая 2027 года указана на официальном сайте. Региональные маршруты, время, услуги, договорённости и тарифы пока требуют утверждения. Карта условна; высотный профиль не строится без данных промера. Гарантий самоокупаемости нет.

29 статей: 3 196 300 ₽; резерв 15%: 479 445 ₽; итого: 3 675 745 ₽. При отдельном включении производства на 1,3 млн ₽ расширенный бюджет с резервом составляет 5 170 745 ₽. Доходы рассчитываются как сценарий с комиссией 5%; принадлежность доходов должна быть закреплена соглашением.

## Работа с правками

Правки сохраняются только в браузере. Главная и калькулятор имеют отдельные модели. Общая синхронизация и защищённый кабинет отсутствуют. Для передачи коллегам на главной выгружайте JSON (смета, дорожная карта, слоты); в калькуляторе — Excel. Импорт JSON заменяет соответствующие разделы после проверки файла. Сделайте экспорт своих правок перед импортом чужих.
